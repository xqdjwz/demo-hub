基础设置

导入 / 导出 / 上传数据

导出会把当前站点、文章、设置与浏览量打包为 JSON 文件备份；导入/上传会用 JSON 内容覆盖当前数据。 未配置 GitHub 时，数据仅保存在当前浏览器本地，清除浏览器缓存后会恢复为站点内置数据。

GitHub 仓库配置（Cloudflare Pages 可直接连接本仓库发布）

填写保存后，前台会优先读取仓库中的 JSON；后台增改站点、文章与设置时会自动提交一次更新。 Token 只存在本机浏览器，不会上传到第三方。
